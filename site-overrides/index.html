Get Scriptable

Install Scriptable on your iPhone. It's the app that runs the widget.

02

Download and unzip

Save the widget kit to Files, then unzip it. You'll get one script and an artwork folder with 96 seasonal scenes in both square and wide formats.

03

Add the script

Create a new script called Seasonal Hourly Weather in Scriptable. Copy and paste the JavaScript file.

04

Import the artwork

Run the script inside Scriptable. Tap Choose artwork folder and pick the extracted SeasonalWeatherArt folder. Allow location access.

05

Add your widget

Add a small or medium Scriptable widget to your Home Screen, then select the Seasonal Hourly Weather script in its settings.

BEFORE YOU GO

A few good questions.

Does the website use my location?+

No. This site only shows illustrative sample forecasts and does not request geolocation. The installed iPhone widget requests location permission from Scriptable to look up the local forecast.

What happens to my location data?+

Scriptable keeps a recent location cache on your device, and the widget sends your coordinates to Open-Meteo to retrieve weather forecasts. This site has no analytics or account system by default. Review the code before installing it.

Will the pictures animate?+

No. iOS widgets use snapshots, so the image changes when the operating system allows the widget to refresh. The script requests a 30-minute refresh interval, but iOS ultimately decides when it refreshes.

Can I customize the layout?+

Yes. Choose a small or medium Scriptable widget and the single script adapts automatically. You can also adjust typography, spacing, and test images in SETTINGS. You can also edit any of the bundled backgrounds.

Is this an official Apple Weather widget?+

No. Seasonal Weather is an independent Scriptable project, using forecast data from Open-Meteo. Tapping the widget attempts to open Apple Weather using an unofficial URL scheme, which may not work on every iOS version.
